# L3Hub v3.3.1.2

本版整合开发分支，新增 DeepSeek 平台账号登录与模型分组，并修复点按涟漪和设置列表的交互细节。

## 新增

- **DeepSeek 平台账号登录**：可通过浏览器授权使用账号，查看模型目录、充值余额和赠金，支持添加、停用和退出多份账号。
- **模型按 Key 或账号分组**：分别查看和添加各分组的模型，为模型指定使用的 Key 或账号；重新添加同名模型时保留已配置的价格。
- **DeepSeek 账号 OCR**：支持通过账号使用 OCR 模型；模型编辑页按提供商实际能力显示可用的内置工具。

## 改进与修复

- 恢复自定义点击区域的 Material 3 涟漪，发送／停止按钮的涟漪颜色跟随按钮前景色。
- 设置列表的从属选项独立展开和收起，修复末项圆角、条目间距和自定义角型按压时的突变。
- 调色板、悬浮窗图标和文件选择面板使用一致的前进、返回过渡。
- 保留模型编辑草稿，避免余额刷新或登录状态更新覆盖尚未保存的内容。
- 限制 Kelivo 导出可读取的附件目录，并隔离临时附件文件名，防止恶意附件路径越界。
- 新增账号鉴权头的日志遮罩，日志导出不包含该鉴权头的原文。
