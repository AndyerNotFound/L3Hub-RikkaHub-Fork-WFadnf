# L3Hub v3.3.1.4

本版把 Rikkahub Revised 的高级外观、富文本与聊天渲染搬了进来，上下文门限收成一个 MAX，并补上视频附件与离线消息预览。

## 新增

- **高级外观（默认关闭）**：设置 → 偏好设置 → 高级外观设置。页卡、顶栏胶囊、输入区、聊天坞、气泡、富内容框各自可选材质与模糊半径；模糊上限按系统给（26–30 无可实时模糊、31/32 最多 12dp、33+ 最多 40dp，折射另算），网格渐变在 33+ 试 AGSL、失败回落 Kotlin 绘制。关闭总开关时一切照旧，旧的模糊路径不受影响。
- **受管背景图与自动强调色**：图片导入后只记 `upload/` 下的相对路径，加载前校验路径、大小（16 MiB）与两轴尺寸；普通页、聊天、全屏预览、设置左栏分别决定要不要画。可从图片取强调色，缺图或不透明度 0% 时退回主题色与助手背景，助手已配置的背景不会被删。
- **忙态降级**：滚动、键盘弹出、生成中、省电、关闭动效或内容还在流式增长时，高级材质退回静态着色，图片本身的模糊不跟着取消，读起来不会花。
- **独立窗口只给静态材质**：对话框、两类下拉、菜单、Sheet、Popup 都不跨窗口采样父窗口像素，按当前主题色合成不透明的底与描边。
- **富文本**：公式走原式 → 兼容候选（如 `\dfrac` → `\frac`）→ 文本近似三级回退，布局失败不再显示一堆 TeX；代码围栏语言归一化（`yml`/`kt`/`sh` 等）；ANSI/SGR 支持 16 色、256 色、truecolor 与常用字形；diff 有独立样式；`echarts` 只认严格 JSON，画原生图表。
- **图片与视频附件**：生成图按原比例收在 82% 宽度内，空地址显示骨架、失败可重试；助手视频是 16:9 卡片，受管本地文件与有读授权的 `content://` 可在应用内黑底全屏播放，`http(s)` 交给系统播放器。
- **离线消息预览**：消息菜单里的预览换成隔离页——禁脚本、禁网络、禁文件与 DOM 存储，Markdown 图片只留文字，地址只显示为可复制文字，带独立缓存与体积上限。

## 改进与修复

- **上下文门限只留 MAX**：模型编辑页从 WARN / MAX 两个门限收成一个 MAX 输入，留空表示不设上限；预设按模型已知窗口的 90% 封顶（基准 524288）。用量条、Web UI 进度条、发送拦截与自动压缩都只看这一个值，没有正的 MAX 就不自动压缩。
- 修正合并带进来的两处编译错误：`AnsiCodeBlock` 误用 `JetBrainsMono`，`LiquidGlassSettings.edit` 的 `transform` 改成带接收者的 lambda。
- 去掉模糊的重复着色，聊天正文不再混进高级模糊的取样源；关闭高级外观时仍用旧列表源。
- 顶栏整条底与顶栏胶囊分开控制，胶囊跟着页卡材质与着色浓度走，不单独抓一层实时模糊。
- 横屏三栏不再给普通页加图片遮罩；需要时用「聊天文字可读性」补遮罩。
- Web UI 的上下文用量条改成单条 MAX 进度，模型没有正的 MAX 时整块不显示。
- 应用图标、Web UI favicon 与文档配图统一换成 L3Hub。
